

## 三択選択肢の関連性を改善

- 三択のダミー選択肢を「同じジャンル」だけでなく「近いカテゴリ」から選ぶように変更
- 例：
  - 県庁所在地の問題 → 都市・県庁所在地・地理系の選択肢
  - 動物の問題 → 動物系の選択肢
  - 食べ物の問題 → 食べ物系の選択肢
  - 宇宙の問題 → 宇宙系の選択肢


## 三択選択肢の細カテゴリ対応

- どのジャンルを選んでも、三択の選択肢を近いカテゴリから出すように変更
- 理科は「元素・化学・イオン・生物・物理・地学」に分けて選択肢を出します
- 地理は「県庁所在地・首都・地形・気候・産業」に分けて選択肢を出します
- 数学は「方程式・関数・確率・三角比・微積」などに分けて選択肢を出します
- ジャンルランダム時も同じ細カテゴリを優先します
